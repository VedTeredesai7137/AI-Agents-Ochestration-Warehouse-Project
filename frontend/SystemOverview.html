04 / WHY USE AI HERE?

Routine traffic needs predictable, fast rules. Exceptional recovery can have several plausible strategies: wait, yield, take a detour, re-auction work or change charging plans.

FAST LAYERCNP, A*, collision reservations, battery policy and deterministic recovery run without an LLM.
SLOW LAYERLangGraph asks the configured model for structured actions only for an exceptional incident. Unrelated agents keep operating.

THE SAFETY CONTRACT

  1. SchemaFive supported actions. Unknown fields and missing parameters are rejected.
  2. World validationReachability, battery, ownership and short-horizon path conflicts are checked without mutating the warehouse.
  3. Human reviewValid plans with warnings or a score below the policy threshold pause before execution.
  4. Live execution checkStale ownership or new risks stop execution. Prepared actions commit under the simulation lock.

05 / INCIDENT PLAYBOOK

Awaiting run budget
Structural collapse

Obstruct an eligible aisle. A* replans immediately; task and charger access stay protected.

Persistent deadlock

Escalate a reciprocal pair only after deterministic recovery and six further failed-movement ticks.

Robot immobilization

Temporarily disable movement and bidding. Reassign safely through CNP, then clear the fault at completion.

Charger outage

Take an unoccupied bay out of service, replan charging traffic, then restore the bay.

Urgent-order disruption

Promote an owned order to CRITICAL. A release re-enters the existing emergency CNP flow.

Manual, automatic and escalated incidents consume the same run budget. A manual request postpones the next automatic event. Queued incidents have no physical effect and do not pin robots. A run may finish before using every slot.
